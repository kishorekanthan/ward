# Security policy

## Reporting a vulnerability

A vulnerability is a weakness someone could use to cause harm, for example running their own code in an app that uses Ward, or reading data they shouldn't.

**Please don't report security problems in a public issue, pull request or discussion.** Public reports put people at risk before a fix is ready.

Report it privately instead:

1. Go to the [Security tab](https://github.com/kishorekanthan/ward/security) of this repository.
2. Click **Report a vulnerability** and fill in the form. Only the maintainers can see it.

If you don't see that button, open a public issue titled "Private security contact needed", with **no details** of the problem, and a maintainer will arrange a private channel with you.

Please include, if you can:

- the Ward version (git tag) affected;
- what someone could do with the problem;
- the steps or a small example that shows it.

## What happens next

- We aim to reply within 7 days to confirm we've received your report.
- We'll keep you updated while we work on a fix, and agree with you when to make it public.
- With your permission, we'll thank you by name when the fix is released.

## Supported versions

Fixes go into the latest release only. Please upgrade to the newest tag before reporting, if you can.
